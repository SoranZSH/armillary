# 浑天图谱 · 设计理念

这篇文档说明浑天图谱为什么长成现在这样：用了什么隐喻，遵守哪些设计原则，在关键处怎样取舍，以及哪些想法试过之后被推翻。它不涉及源码实现。

---

## 一、一个隐喻：浑天仪

名字取自东汉张衡的浑天说：“浑天如鸡子，天体圆如弹丸，地如鸡子中黄，孤居于内。”大地居中，正好对应“地基在中心”。英文名 Armillary 即浑天仪。

整体形态是**“远看是浑天仪，近看是地图”**：
- 结构沿用全世界都看得懂的太阳系，负责易懂；
- 皮肤用中国古代天文和矿物颜料的意象，负责记得住。

有一个熟悉的隐喻，用户才有方位感。CodeCity 等软件可视化研究也发现，隐喻配上严格的摆放规则，能明显减少迷失。

## 二、设计原则

遇到取舍时按顺序优先：

1. **3D 必须挣得它的位置。** 可视化领域的经典守则是“不做没有理由的 3D”：遮挡会藏住信息，透视会扭曲大小，倾斜的文字读不清（Munzner）。我们用 3D 的理由只有两个：同心圈层这个空间概念，以及让人记得住、愿意分享。所以 3D 只做总览和定位，阅读、比较、学习都回到 2D。
2. **先总览，再缩放和过滤，最后按需看细节。** 这是 Shneiderman 的信息检索口诀，直接对应四级缩放：浑天总览 → 聚焦行星 → 行星内部（2D）→ 地基卡。
3. **一个视觉通道只编码一件事。** 半径、颜色、大小、速度各管一件，动画不为好看而动。
4. **每个位置都能用一句话解释。** 解释不了的摆放就是错的摆放。
5. **受限导航，不让人迷路。** 锁定俯仰角，禁止翻转，提供面包屑和罗盘，Esc 逐级返回。
6. **少画线。** 默认不画依赖线，选中时才出现。研究表明，类似地图的画法在完成任务、记忆和投入度上都优于满屏连线。
7. **事实与解释分层标注。** 计算出的指标、人工策划的内容、AI 撰写的讲解，在界面上用不同标记区分。AI 讲解标注“AI 生成 · 待校对”。
8. **尊重动效偏好。** 系统开了“减少动态效果”时，关闭自动旋转，镜头飞行改为淡入淡出。
9. **先功能，后形式。** 先做 2D 数据版，确认分组和层级站得住，再套 3D 外壳。

## 三、数据怎样变成天体

| 视觉 | 编码什么 |
|---|---|
| 半径（轨道） | 抽象层级：越靠内，这个领域的代表包平均越接近依赖底层 |
| 角度与颜色（扇区） | 所属的大领域，四象配色 |
| 大小 | 承重度，分五档。人眼很难比较连续变化的面积，分档后一眼可读 |
| 自转与星尘转速 | 活跃度 |
| 引力线 | 包与包之间的直接依赖，只在选中时出现，每条线都能列出背后的包级例子 |

**行星不各自公转。** 各自公转会让相对方位不断变化，用户每次回来都要重新找。所以整个星系同步慢转，方位固定好记；动感留给行星自转和星尘。

**辨识度高于真实星系。** 真实的行星远看只是颜色相近的小点。这里反过来：
- 每颗行星有专属的颜色深浅和传统纹样（云纹、回纹、水波纹、冰裂纹……），色弱用户也能靠纹样分辨；
- 名字常驻；
- 第二次打开时，用户还认得“上次看的那一颗”。

## 四、说清楚圈层说什么、不说什么

最初的设计稿写过一句“外圈的一切都站在内圈之上”。专家审阅指出，用户会把它读成“外圈依赖内圈”，而这并不成立：例如 torch 并不依赖 click。

我们改了说法，并补上能核对的证据：
- 圈层只说明一个领域的代表包**平均**离依赖底层多远，不说明两颗行星之间一定有依赖；
- 行星卡列出“它的成员直接依赖哪些行星”，每条关系附上包级例子；
- 新增“查证”：任选两个地基，分三段给证据——依赖链、是否同一领域、哪些项目同时用过；
- 每段都写明“图中没有收录不等于一定没有关系”。

这一条后来成了全产品的底线：**能画出来的，都要能查证；查不到的，要如实说查不到。**

## 五、四季扇区：让方向有规律

最初四个扇区按“应用、训练、推理、数据”排列，结果数据和训练不相邻，按学习顺序走的航线只能在圆周上来回穿越。

后来改为按 AI 生命周期顺时针排开，并对上“春生夏长秋收冬藏”：

> 北方玄武 · 冬藏 · 数据 → 东方青龙 · 春生 · 训练 → 南方朱雀 · 夏长 · 推理与部署 → 西方白虎 · 秋收 · 应用 → 回到数据

- 数据像水一样汇聚沉淀，模型从数据里长出来，算力如火，最后把能力收成产品；
- 四象的方位和颜色不变，只是换了对应的领域；
- 外圈用四段铜色箭头标出流转方向，所有航线都顺着这个方向绕地心走，不来回折返。

## 六、减少视觉焦点

第一版有 30 颗行星，卫星是一颗颗独立的小球，试用反馈是“眼花缭乱”。我们做了三处收敛：
- **30 多个细分领域合成 13 颗行星。** 细分领域变成行星里的“分区”，在行星卡里展开。
- **卫星改成卫星带。** 总览时，应用只画成一圈倾斜的星尘；点击星带后，镜头凑近，应用才从星尘里沿方位依次铺开。
- **通用工具库改成铜环。** Python、Node.js 的通用工具库单个分量小、数量多，画成大球会抢走视线，于是改成环绕地心、带刻度的浑天仪式铜环。约定是：**星尘 = 应用，铜环 = 工具。**

## 七、证据优先

浑天图谱的每个结论都给出可核对的来源：

| 功能 | 给出的证据 |
|---|---|
| 回执（读懂我手上的项目） | 读到了哪些文件；直接依赖分三类；间接用到的地基；检测到的外部引擎客户端；只凭清单判断不了的部分 |
| 查证 | 完整依赖路径；分区与层级；共同使用的项目 |
| 应用对账 | 种子应用里多少成了卫星，没上图的每一个都写明原因，例如“主要语言是 Go，它的 Python 客户端在图上，本体不在” |
| 地基卡 | 为什么它在这颗行星：人工锚点、数据归属比例，还是人工改归 |

**行星分组的方法。** 我们没有直接用聚类结果，因为共现关系只会把“互补”的包聚在一起，不会把“可互相替代”的包聚在一起。例如几个推理引擎很少被同一个项目同时使用，纯聚类永远聚不成“推理引擎”这一类。

现在的做法是：
- 每个领域只人工指定少量代表包作为锚点；
- 其余成员的归属全部由依赖关系决定；
- 再用独立的聚类结果交叉校验；
- 归属依据写在每张地基卡上。

## 八、按职业看地图

不同职业的新人要学的东西不一样，看到的地图也应该不一样。

- **职业透镜。** 新人开发、产品经理、测试、算法新人，各自眼里 13 颗行星的分量不同，并配一句标签。例如：
  - 产品经理眼里的“推理与分布式计算”是“成本与速度”；
  - 算法新人眼里的“深度学习框架与加速”是“主战场”。

  地图按分量分档点亮，卡片里先讲你这个职业。
- **航线。** 每个职业两条：入门航线和任务航线。
  - 每条航线先给一道结业题，例如“换便宜模型，怎样测出能不能换”；
  - 每一站回答一个问题，附依赖证据、自测和参考答案。

  航线是“从问题出发的学习路径”，不是按覆盖率算出的清单：我们试过后者，结果各职业看到的几乎一样，也没有学习顺序。

## 九、新手不迷路

- **两种入口。** 首次进入时，“浑天观测站”给出一个能用现有数据回答的问题，带人走完一次“抵达行星 → 读证据 → 判断关系”；也可以直接自由漫游。之后有一分钟的新手引导，需要动手的步骤要等用户真的点了才前进。
- **每个“打开”都能关回去。** 点亮的航线、点亮的星图，都能用同一个按钮关掉；收起面板时，底部状态条保留一个关闭入口；Esc 一层层往外退。
- **状态可分享。** 每个视图都有自己的链接，发给别人打开就是同一个画面。

## 十、浑天中国风

**三个视觉母题**
- **浑天仪**：轨道是带刻度的细铜环。
- **敦煌星图**：借它“点加细线”的画法画航线。
- **地如鸡中黄**：中心是中央之黄的地心。

**配色**
- 背景用玄青，不用纯黑；另有绢色的“绢本模式”，致敬画在绢上的敦煌星图。
- 四个扇区用四象的青、赤、白、玄，中央为黄。
- 金色全场只留给“客星”。
- 颜色从不单独承载信息，每种编码都同时有图例和文字。

**声音**
全部在浏览器里实时合成，不加载音频文件，默认静音，由用户主动打开。
- 背景是生成式的古琴乐句，下面垫着缓慢换和弦的笙，偶尔有箫。
- 点击时五音配五方：玄武羽、青龙角、朱雀徵、白虎商、地心宫。
- 不同天体音色各异：
  - 行星是编钟，内轨低沉、外轨轻亮；
  - 卫星带是古筝刮奏，卫星是古琴单音，星数越高音越高；
  - 地基是木鱼，工具环是碰铃；
  - 返回是下行两音。

## 十一、可持续：永久免费，自愿打赏

- 网站对所有人永久免费，打赏不解锁任何功能，款项只用于平台维护与进一步完善。
- **入口不打扰。**
  - 电脑端只在星系右侧放一枚半透明的“赏”字印章，静止不动；鼠标移上去才变亮，并露出“支持一下”的标签；
  - 有物体被选中、引导或导览进行中、展开读图说明时，印章自动让位；
  - 不自动弹窗，没有默认选中的金额。
- **付款前说清楚。** 付款前用醒目的小纸条写明：这里没有付费服务，打赏是自愿赠与。
- **只认渠道确认。** 是否到账只看支付渠道的确认；连点、重复提交都不会重复扣款。

## 十二、借鉴与区别

| 参考 | 借了什么 | 避开了什么 |
|---|---|---|
| Software Galaxies（npm 3D 依赖星空） | 离线预计算 + 静态托管 | 自由飞行和满屏连线 |
| Map of GitHub | 聚类 + 人工定名，语义缩放 | 它衡量“相似”，没有方向 |
| Thoughtworks 技术雷达 | 同心环只编码一个有序变量，象限做大类 | 全靠人工评审 |
| NASA Eyes on the Solar System | 时间回放、导览、可分享的视角链接 | 控件太多，新手无从下手 |
| CNCF 云原生全景图 | 公开收录标准，入门路线图 | logo 墙看不出依赖关系 |
| Connected Papers | “前置 / 后续”两个清单 | 每次只看一个邻域 |
